    Garden 0

    Garden 0 is a manga created by Zaffy. It uses an innovative pixel art style and features several characters connected to other Project Lumina products.

    The manga is published in English as a free-to-read online release, with limited physical editions in Italian and English.

    Overview

    The manga follows Eyezor, the main character, an immortal combination of Divine, Human and Creation, Sona and Llyv, the first 2 characters Eyezor is going to encounter, and also the main side characters. Eyezor has just been revived by the Queen, the God of the Hive, an heavenly dimension, in contrast to the Nest, similar to Hell and ruled by the other God, The Sailor. The Queen has given Eyezor 3 main objectives: Bring back to the hive The Creator and The Astronaut, Find the 5 Jurors and kill Asha. The 3 will then embark on a journey of betrayal, elemental magic and suffering, to find out more about Eyezor.

    The first volume is centered around the Prologue, about the Sailor's Betrayal, The Creator's escape and the creation of the universe.

    Development status

    The project is currently on development, and the first volume is already online. If you want to be updated on the new volumes, you can join the Discord server below or check this wiki page.
